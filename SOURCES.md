# Источники данных «Кыв кытш» 

| Что | Источник | Лицензия | Как используется |
|---|---|---|---|
| Коми слова, русские переводы, примеры | Русский Викисловарь, статьи «Коми-зырянский язык», извлечение Wiktextract: https://kaikki.org/ruwiktionary/Коми-зырянский/ (`src/ru_kv.jsonl`, 1 139 статей; ~830 лемм 3–8 букв) | CC BY-SA 4.0 (+GFDL) | основной источник переводов и карточек |
| Доп. коми слова | English Wiktionary через kaikki.org: https://kaikki.org/dictionary/Komi-Zyrian/ (`src/en_kv.jsonl`, 1 161 статья) | CC BY-SA 4.0 (+GFDL) | 283 слова получили ручной русский перевод (`src/ru_gloss_extra.json`, производная работа, CC BY-SA 4.0) и идут в кроссворд; остальные — только бонусные (англ. толкование) |
| **Основной словарь (с 21.10.2026)**: коми-русский словарь GiellaLT / Giellatekno (UiT, Норвегия) | https://github.com/giellalt/dict-kpv-rus (`src/dict-kpv-rus/`, ~27 000 статей, рус. переводы и примеры) | **CC BY 4.0** — коммерция разрешена, нужно только указание авторства (есть в «Об игре» и в карточках) | +13 966 слов; диалектные значения отброшены; религия/брань отфильтрованы |
| Ручные исправления первых значений | `src/ru_gloss_fix.json` (11 слов) | CC BY-SA 4.0 | замена редкого/странного первого значения Викисловаря |
| Частоты | дамп коми Википедии https://dumps.wikimedia.org/kvwiki/latest/ → `tools/kvwiki_freq.py` → `src/kvwiki_freq.json` | тексты CC BY-SA 4.0; используются только счётчики | сложность/порядок уровней |

Условия CC BY-SA 4.0: указание авторства (Викисловарь/Wiktionary + ссылка на лицензию — есть в «Об игре» и в карточках), производные данные
(словарь/карточки) — под той же лицензией. Коммерческое использование разрешено. Код игры под ShareAlike, по общепринятому толкованию, не попадает
(перед магазинами подтвердить, как и для татарской игры).

Проверено (21.10.2026):
- GiellaLT `lang-kpv` (морфология, https://github.com/giellalt/lang-kpv) — LGPL-3.0; в игре не используется.
- Apertium `apertium-kpv` — GPL-3.0, по сути пустой (23 КБ); не используется.
- FU-Lab / komikyv.ru / dict.fu-lab.ru («Кывкуд») — открытой лицензии нет: «бесплатно, некоммерческая основа», словари — оцифровка бумажных изданий (Русско-коми словарь 2011, ИЯЛИ Коми НЦ), права у авторов. **Не используем**; для использования нужно письменное разрешение (komi@fu-lab.ru).

Звуки — синтез WebAudio (js/sound.js), музыки нет. Фоны — процедурный SVG (js/art.js); фото-фоны глав ещё не сделаны. Иконка — img/icon.svg (своя).
